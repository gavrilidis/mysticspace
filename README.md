# MYSTIC SPACE — Навигационная система судьбы

Интерактивный веб-проект с 3D-космосом на Canvas, симуляцией движения звезд, картами Таро, синастрией, лунным календарем и матрицей судьбы.

## Особенности
- **Интерактивный 3D-космос**: процедурная вселенная на HTML5 Canvas с возможностью выбора космических палитр, управления скоростью полета, зумом и режимами ориентации.
- **Таро дня**: интерактивная колода с анимацией переворота карт и генерацией новых арканов.
- **Астрологическая синастрия**: экспресс-анализ совместимости знаков зодиака.
- **Лунный цикл**: динамический трекер фаз луны и лунных дней.
- **Матрица судьбы**: экспресс-расчет кода предназначения по дате рождения.

## Технологии
- HTML5 / Vanilla JavaScript
- Canvas 2D API (3D projection & particle system)
- Tailwind CSS
- Google Fonts (Cormorant Garamond, Inter, JetBrains Mono)

## Запуск локально
Просто откройте `index.html` в любом современном браузере или запустите локальный сервер:
```bash
python3 -m http.server 8080
```
